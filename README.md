`main.py` writes one line - awkward small talk from one robot to another in an elevator - to /output/entry.txt.

One robot awkwardly compliments another's firmware, then panics about being reported to maintenance.

Run: `python3 main.py`
Local test: `ENTRY_OUTPUT=./output/entry.txt python3 main.py && cat ./output/entry.txt`
